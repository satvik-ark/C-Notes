# My Journey of Learning C Programming 🚀

Welcome to my C Programming repository!

This repository documents my journey of learning **C programming from the fundamentals to more advanced concepts**. It is a collection of my notes, code examples, practice problems, experiments, and progress as I explore the world of programming.

## 🎯 About This Repository

I created this repository to maintain a structured record of everything I learn while studying C programming.

Rather than simply watching tutorials or reading theory, I believe in learning by doing. Every concept I study, every problem I solve, and every mistake I encounter will contribute to this repository.

The goal is not just to learn the syntax of C, but to develop a deeper understanding of how programs work and how computers execute instructions.

## 📚 What I'm Learning

Throughout this journey, I will be covering topics such as:

- **Fundamentals:** Introduction to C, program structure, compilation, and execution.
- **Variables & Data Types:** Variables, constants, operators, and type conversions.
- **Input & Output:** Using `printf()` and `scanf()`.
- **Control Flow:** Conditional statements, loops, and decision-making.
- **Functions:** Function declarations, definitions, parameters, recursion, and scope.
- **Arrays & Strings:** Working with collections of data and character sequences.
- **Pointers:** Understanding memory addresses, pointer arithmetic, and dynamic memory.
- **Structures & Unions:** Organising complex data using user-defined data types.
- **File Handling:** Reading from and writing to files.
- **Data Structures:** Exploring fundamental data structures and their implementation in C.

This list will evolve as I progress and explore more advanced concepts.

## 💡 My Learning Philosophy

I don't expect to understand everything on the first attempt.

Programming is a process of experimenting, debugging, making mistakes, and gradually developing the ability to think logically.

I want to focus on:

1. Understanding concepts rather than memorising syntax.
2. Writing code regularly and practising problem-solving.
3. Learning how memory management and low-level operations work.
4. Writing clean, readable, and efficient code.
5. Revisiting previous concepts and improving my implementations.

## 📈 Progress & Updates

This repository will be updated regularly as I learn new concepts, solve problems, and build a stronger foundation in programming.

It represents my progress, including the mistakes, experiments, and improvements along the way.
